Supported format and important notes

Accepts the class-list format with student name, parent name, parent email, parent phone and LRN; a two-column Name / LRN list; separate First / Middle / Last columns; or an existing ASTIG file. Blank columns, numbering columns and extra columns are ignored. If a workbook has several sheets, only sheets with an LRN column are converted (so an "address" sheet is skipped); if no sheet has an LRN column, every sheet with names is converted.

Output columns: LRN, First Name, Middle Name, Last Name, Extension, Parent Mobile No, Parent Email.

Names are split using the heading: “Last Name, First Name, Middle Name” means Last first, whether or not there are commas. Common second names (Mae, Anne, Grace, Joy…) stay in First Name. Section rows such as “BOYS:” and “GIRLS:” are skipped. Check anything flagged under Review and edit. Missing or invalid LRNs are preserved for correction. Duplicate LRNs are flagged across all selected files. Parent names have no field in the ASTIG template.

Ten-digit mobile numbers beginning with 9 receive a leading 0. No LRN digits are guessed. Downloads include all listed students, including any unresolved warnings. ASTIG may reject invalid records. Select the grade and section in ASTIG when importing. Save older .xls files as .xlsx in Excel first.

Choosing a save folder works in Chrome, Edge and other Chromium browsers. In browsers without this feature (Firefox, Safari), files go to your normal Downloads folder instead; turn on “Ask where to save each file” in your browser settings if you want a prompt.
