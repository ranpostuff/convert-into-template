Supported format and important notes

Accepts the class-list format with student name, parent name, parent email, parent phone and LRN; a two-column Name / LRN list; or an existing ASTIG file. All recognized worksheets are converted separately. Save older .xls files as .xlsx in Excel first.

Output columns: LRN, First Name, Middle Name, Last Name, Extension, Parent Mobile No, Parent Email.

Names without explicit separators are split provisionally. Check them under Review and edit. Missing or invalid LRNs are preserved for correction. Duplicate LRNs are flagged across all selected files. Parent names have no field in the ASTIG template.

Ten-digit mobile numbers beginning with 9 receive a leading 0. No LRN digits are guessed. Downloads include all listed students, including any unresolved warnings. ASTIG may reject invalid records. Select the grade and section in ASTIG when importing.
